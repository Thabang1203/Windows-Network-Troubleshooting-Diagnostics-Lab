# Windows Network Troubleshooting & Diagnostics Lab

## Overview

A hands-on IT Support project focused on diagnosing common Windows networking issues using a **structured troubleshooting methodology**.

The goal was to understand **what to test, why to test it, and how to interpret the results**, rather than simply memorizing commands.

## Scenarios Covered

1. DHCP and APIPA diagnostics
2. DNS resolution issues
3. Default gateway connectivity
4. Connected but no internet
5. IP address conflict investigation

## Tools Used

- `ipconfig /all`
- `ping`
- `nslookup`
- `tracert`
- `arp -a`

## Troubleshooting Approach

1. Check IP configuration
2. Test default gateway connectivity
3. Test external network connectivity
4. Test DNS resolution
5. Trace the network path
6. Test browser access
7. Document findings and results

## Skills Demonstrated

- Windows 11 Troubleshooting
- TCP/IP and IPv4
- DHCP and APIPA
- DNS Troubleshooting
- Default Gateway Diagnostics
- ARP and MAC Addressing
- Network Diagnostics
- L1 IT Support
- Fault Isolation
- Technical Documentation

## Key Takeaway

This project strengthened my ability to **troubleshoot network issues systematically, isolate faults, and interpret diagnostic results** rather than relying on guesswork.

It also reinforced the importance of protecting production environments and making configuration changes only when **authorized and necessary**.

I am continuing to develop my **IT Support, networking, and Windows administration skills** through hands-on practice, feedback, and continuous learning.
